# Rust Platform Compatibility Guide

A browser-based reference guide covering Rust application compatibility across Windows, macOS, Linux, and other computing platforms.

## Overview

Rust is a cross-platform programming language that compiles applications into native machine code. This guide explains which operating systems and processor architectures can run applications developed with Rust.

The guide is intended for software developers, independent creators, and anyone interested in building and distributing Rust applications.

## Features

- Windows compatibility, including legacy operating systems
- Apple macOS support for Intel and Apple Silicon
- Linux distributions and ARM-based computers
- Mobile, Raspberry Pi, and WebAssembly platforms
- Rust compilation targets and executable formats
- Cross-platform application architecture overview
- Responsive HTML layout with interactive navigation
- Print-friendly presentation

## How to Use

1. Download `rust-platform-compatibility-guide.html`.
2. Open the file in a modern web browser.
3. Use the navigation links to explore the supported platforms.
4. Select **Print this Guide** to print a reference copy.

No installation or web server is required.
